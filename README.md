# 💄 Lipstick Slot

Ein glamouröser Mobile-First Slot-Automat mit Lippenstift-Thema von MAC, Yves Saint Laurent (YSL) und NYX.

## 🎰 Features

- **Mobile-First Design**: Optimiert für Smartphone-Browser (Portrait-Modus)
- **3 Premium-Marken**: Elegante Lippenstift-Symbole für MAC, YSL und NYX
- **9 Varianten**: Je 3 verschiedene Farbtöne pro Marke
- **Klassische Slot-Mechanik**: 3 Walzen mit Mittellinien-Gewinn
- **Smooth Animationen**: Zufriedenstellende Dreh- und Gewinn-Effekte
- **Sound-Effekte**: Web Audio mit Stummschaltung (🔊/🔇)
- **Glamouröse Ästhetik**: Dunkles Design mit Roségold und Gold-Akzenten
- **Deutsche Benutzeroberfläche**: Komplett in Deutsch

## 🎨 Symbols

### MAC (Bold Black & Red)
- Ruby Woo (Rot)
- Velvet Teddy (Braun-Rosa)
- Candy Yum-Yum (Pink)

### YSL (Luxuriös Gold & Schwarz)
- Rouge Pur (Weinrot)
- Nude Beige (Beige)
- Rose Stiletto (Pink)

### NYX (Verspielt Neon & Schwarz)
- Neon Pink (Neon-Pink)
- Berry Blast (Lila)
- Coral Pop (Koralle)

## 🏆 Gewinnregeln

- **3 identische Symbole**: 10x Einsatz
- **3 gleiche Marke** (beliebige Farbtöne): 3x Einsatz

## 🚀 Installation & Start

### Voraussetzungen
- Node.js (Version 18 oder höher)
- npm

### Setup
```bash
npm install
```

### Entwicklungsserver starten
```bash
npm run dev
```

Öffnen Sie dann Ihren Browser und navigieren Sie zu der angezeigten lokalen URL (normalerweise `http://localhost:5173`).

### Production Build
```bash
npm run build
```

Die fertige App befindet sich dann im `dist/` Ordner und kann auf jedem statischen Hosting-Service deployed werden.

### Preview des Production Builds
```bash
npm run preview
```

## 🎮 Spielanleitung

1. **Einsatz wählen**: Tippen Sie auf 1, 5 oder 10 Credits
2. **Drehen**: Tippen Sie auf den großen "DREHEN" Button
3. **Gewinnen**: Bei Übereinstimmung erhalten Sie Credits zurück
4. **Sound**: Nutzen Sie den 🔊/🔇 Button zum Stummschalten

**Startguthaben**: 100 Credits

## 📱 Mobile Optimierung

- Responsive Design für Smartphone-Bildschirme (max. 420px Breite)
- Touch-optimierte Bedienelemente
- Safe-Area-Unterstützung für moderne Geräte
- Viewport-optimiert für Portrait-Modus

## 🛠️ Technologie

- **Vite**: Schneller Build-Tool und Dev-Server
- **Vanilla JavaScript**: Keine Framework-Abhängigkeiten
- **CSS3**: Moderne Animationen und Layouts
- **Royalty-Free Fotos**: Echte Lippenstift-Bilder von Unsplash und Pexels
- **Web Audio API**: Native Browser-Sounds

## ⚠️ Hinweis

Nur zur Unterhaltung. Kein echtes Geld. Keine Backend-Verbindung. Alle Daten bleiben lokal im Browser.
